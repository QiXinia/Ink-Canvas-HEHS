  // 避免拖到屏幕边缘时面板顶出可视区、按钮无法点击。
  private settingsPanelOffsetX(): number {

    const panelW = Math.min(w * 0.94, this.fullLayout() ? 460 : 380);

## 未能用代码实现的一项：跨任意应用悬浮

查 SDK `@ohos.window.d.ts` 确认：创建系统级悬浮窗（`WindowType.TYPE_FLOAT`）的 `window.createWindow` 标注
`@permission ohos.permission.SYSTEM_FLOAT_WINDOW`，属 **system_basic** 级，普通/调试签名**无法申请**；也不存在让普通应用主动置顶到其他应用之上的 API。所以“工具栏自动悬停在微信/浏览器/PPT 之上”无法靠应用代码强做。

已提供并可用的官方路径（代码已就绪）：
1. 点工具栏「浮批」→ 画布隐藏、窗口透明，仅剩工具栏；
2. 在系统**多任务卡片**右上角把本应用切为「悬浮窗」（`module.json5` 已声明 `supportWindowMode: floating`）；
3. 此时应用窗口浮在其他应用之上，工具栏与透明批注层即可直接覆盖批注。
提示文案已改为明确的这一步操作（并注明“普通应用无法自动置顶”）。

若必须**自动**置顶，唯一途径是申请系统签名并声明 `SYSTEM_FLOAT_WINDOW`，这超出当前调试签名的能力范围。
