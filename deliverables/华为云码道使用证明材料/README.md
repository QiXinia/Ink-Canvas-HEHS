# 华为云码道使用证明材料

本文件夹依据用户提供的码道截图、全量日志包与鸿蒙操作录屏整理，日期为 2026-11-24。截图保留码道界面标识、原始 Prompt、代码修改和工具执行轨迹。

## 快速查看

打开 `index.html` 浏览截图与视频，或打开各案例 Markdown 查看代码与排错过程。`华为云码道使用证明-摘要.pdf` 摘自产品说明书中的码道四页。

## 目录

- `01-AI交互与Prompt截图` 保存 8 张用户提供截图的整理副本。
- `02-代码生成与重构记录` 包含公式识别、工具栏与面板、化学绘制三个案例。
- `03-排错与验证记录` 包含编译迭代、触摸命中、OCR 边界三个案例。
- `04-鸿蒙运行素材` 包含三段原始录屏副本及按时间截取的预览帧。
- `05-来源与索引` 保存源文件名、SHA-256、日志行号与分类索引。

## 材料处理说明

- 原始日志包共 130 个文件，解压后约 919 MB。采用流式读取，节选与本项目相关的用户可见回复、Prompt 和工具调用，按源文件与行号回溯。日志时间保留原格式，未推断时区。
- 截图中的设备标识已遮盖，文本摘录中的本机用户目录、设备号、链接及网络地址按规则隐去。原日志包自身的 `****` 掩码保持原状。
- 全量原包保留在用户提供目录，索引记录其哈希。本材料只包含评审所需的选段，未复制会话内部推理、记忆元数据和原始网络请求。
- 部分日志不是规范 JSON，摘录通过可见字段恢复，并注明 `partialRecord`。截图和原日志行号用于交叉核对，未补写缺失内容。
- 鸿蒙录屏是用户提供的运行材料，显示书写、折叠、PDF 批注、化学结构和白板流程。配套对话报告 MatePad／HarmonyOS 7.0.0.111 安装与测试。本次未重新连接设备测量延迟、帧率、功耗或全面兼容性。
- OCR 手写公式全链路、自由多窗与分屏覆盖，以及普通应用跨应用悬浮权限仍有边界，各案例中明确保留。
