# Ink Canvas A4 产品说明书

本说明书为 28 页 A4 纵向版式，以 React 构建，用 Chromium 的浏览器打印引擎输出 PDF。修订版重点呈现开源基础上的代码重构、现代 Windows 桌面技术、UI／UX 和触摸适配，以及鸿蒙原生版本的实现范围与验证状态。课堂案例采用全国一卷第 18 题的椭圆推导，并补充立方体截面、47 种图形与真实 AI 协作。

## 交付文件

- `out/InkCanvas-产品说明书-A4.pdf` 为打印成品。
- `dist/index.html` 为构建后的网页入口，配套文件位于同目录。
- `src/App.jsx` 为目录、基础图文页与共用组件，`src/ExpandedPages.jsx` 为架构、鸿蒙与演示专题，`src/EvidencePages.jsx` 为码道交互、代码重构与排错证明，`src/manual.css` 为 A4 和网页阅读样式。
- `out/qa/layout-audit.json` 记录页面尺寸、资源加载与页脚越界检查。
- `SOURCES.md` 记录文档、截图和字体来源。
- `CONTENT-EVIDENCE.md` 将报告中的重构贡献和功能映射到代码与文档，并记录验证边界。
- 网页第 22 页提供椭圆题讲解与可编辑案例下载，第 23 页包含六段本地视频。PDF 保留静态帧与操作说明。
- `public/assets/cases` 保存案例截图、白板、批注 PDF 和源文件哈希记录。`scripts/import-case-assets.py` 可从相邻演示工程重新导入素材，需要 Python、Pillow 和 OpenCV。

## 编辑与重建

在本目录打开 PowerShell，使用 Node.js 运行以下命令。

```powershell
npm.cmd install
npm.cmd run build
npm.cmd start
```

浏览器访问 `http://127.0.0.1:4173`，可以通过目录跳转、页码选单和打印按钮阅读。打印按钮调用浏览器自身的打印功能。

## 导出 PDF

```powershell
npm.cmd run build
npm.cmd run print
node scripts/check-browser.mjs
```

导出脚本使用已安装的 Chromium 浏览器。可通过 `CHROMIUM_PATH` 指定本机浏览器路径。脚本等待本地字体与图片加载完成，使用 A4、零额外页边距、背景图形和 CSS 分页，隐藏浏览器默认页眉页脚。它还生成每页预览图和越界检查结果。

手动打印时选择 A4、纵向、100% 缩放，勾选背景图形并关闭浏览器页眉页脚。

## 设计资源

中文使用 Noto Sans SC，拉丁字母和数字使用 Source Sans 3，图标使用项目随附的 Fluent System Icons Regular。字体及许可均位于 `public/assets/fonts`。全部页面资源本地加载，导出不依赖在线字体服务。

Windows 内容基于 v3.15.0 和当前源码整理。鸿蒙包含早期逻辑互认记录与 2026-11-24 用户补充的设备运行素材。第 20 页三段录屏显示书写、折叠、PDF 批注、化学结构和白板流程，配套码道记录报告 MatePad／HarmonyOS 7.0.0.111 安装和测试。本次未重新连接设备测量延迟、帧率或功耗。AI 截图使用视频工程保存的真实 DeepSeek 回复原样取景，包含成功新建白板页的工具结果，实际生成等待时间未完整呈现。性能数据为本机离屏合成基准。码道章节现已包含用户提供的原始 Prompt、界面截图、代码修改及排错记录，完整材料单独整理。
