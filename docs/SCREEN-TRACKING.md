# 屏幕内容跟随

在“设置 → 实验性设置”启用“屏幕内容跟随”。总开关默认关闭，滚动、缩放、固定区域遮罩、页面记忆和应用适配可分别设置。

## 使用范围

- 屏幕批注适配 Microsoft Word、Microsoft PowerPoint 和 Microsoft Edge。隐藏墨迹或切到鼠标模式后继续读取页面状态，恢复书写时刷新墨迹位置。
- Word 使用原生文档窗口、缩放信息及可访问性正文数据。PowerPoint 编辑区使用原生文档窗口和幻灯片坐标，放映区按幻灯片标识切换。
- Edge 按网页地址识别页面，页面原地大幅替换文本时通过连续文本指纹确认变化。同一页面中的小幅计数和标题变化不会切换批注。
- 跟随采用视图矩阵，保留笔画原始坐标、宽度和可编辑性。写字、擦除、选区拖动或墨迹回放期间延后跟随。
- 正文以外和上层窗口覆盖区域裁切墨迹。页面内宽页眉及高侧栏在确认滚动而自身保持静止后加入遮罩。

## 页面与未变化区域

页面记忆仅保存在本次运行的内存中，按文档、网页与幻灯片分别保留墨迹、图片和撤销记录。关闭程序后这些实验性页面缓存结束，应通过现有保存功能另行保存需要保留的墨迹。

“保留页面中未变化区域的批注”以能够唯一匹配的相同可见段落为依据。整条笔画必须处于该段落区域内，段落变形过大或重复出现时跳过共享。同步包括新增与删除，避免删除的笔画在其他页面重新出现。共享区域跨页同步后会清理目标页撤销记录，避免旧操作引用过期对象。

## 识别限制

目标应用需要提供可访问性正文、滚动或缩放数据。自绘 Canvas、图片式网页、受保护内容、复杂重排和 PowerPoint 放映内的特殊放大界面可能无法获得连续定位。固定区域识别基于可访问性元素及实际滚动，无法保证任意悬浮网页组件都能识别。

定位中断或目标应用暂时无响应时隐藏该页墨迹。恢复定位后继续显示，必要时在实验性设置点击“重新绑定当前批注位置”。该操作以当前墨迹位置建立新的跟随基准。

默认关闭时不启动观察线程和跟随定时器。观察在独立 MTA 线程运行，UI 线程仅应用已取得的快照。读取限于本机应用提供的可访问性和 Office 信息。

## 回归验证

运行单元测试覆盖页面往返、撤销和图片引用、滚动缩放矩阵、DPI 与屏幕原点、独立开关、手势保护、固定遮罩、像素裁切、文本指纹及共享段落删除同步。

```powershell
$env:NUGET_PACKAGES = 'D:\dev-cache\nuget'
dotnet test tests/InkCanvas.Core.Tests/InkCanvas.Core.Tests.csproj -c Release -p:Platform=x64
artifacts/app-screen-follow/InkCanvas.exe --screenfollowcheck=D:\InkCanvas\artifacts\screen-follow-check
```

运行时检查会生成设置界面截图和 JSON 结果，并检查真实 layered window 的墨迹裁切、隐藏期间跟随与页面恢复。在存在可交互输入桌面且没有已有 Office 实例时，检查临时 Word 文档、PPT 幻灯片及独立 Edge 配置。没有输入桌面时明确记录跳过原生交互项，已有 Office 实例也跳过相应检查。
