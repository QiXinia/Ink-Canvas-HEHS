# 板书时光机操作说明

适用版本：WinUI 3 桌面端（本轮增量）。所有课件、批注、课堂记录与音视频默认仅在本机处理。

## 1. 录制

1. 正常打开画板并书写；录制由课堂场景自动开启（或在设置中开启录制）。
2. 录制期间每次落笔 / 擦除 / 清空 / 切页 / 背景切换 / 撤销重做 / PPT 翻页与批注变化都会进入统一时间轴。
3. 事件按「时间 + 会话序号」排序：同一毫秒内的多次操作也保持确定顺序，不依赖系统校时。
4. 录制中事件会增量落盘（约每 2 秒或每 50 个事件），异常退出最多丢最后约 2 秒。

## 2. 暂停与恢复录制

- 浮条次级菜单「暂停录制 / 继续录制」。
- 暂停期间产生的内容**不会**进入时间轴；继续后回放时间轴保持连续，暂停时长不计入有效时长。
- 暂停期间已画的笔画保留在画板上，但不参与本会话回放；如需记录请从头重新录制。

## 3. 打开时光机回放

1. 浮条次级菜单「板书时光机」，选择会话。
2. 顶部：播放 / 暂停、停止（回到开头）、上一笔 / 下一笔、上一事件 / 下一事件、倍速 0.5×–8×、「完整课堂 / 仅板书」。
3. 底部：进度拖动、页码跳转、书签轨道、时间轴缩放 1×/2×/4×、关键位置刻度。
4. 回放使用独立控制器，不会修改原始记录；退出时恢复进入前的页与背景。

## 4. 键盘操作

| 按键 | 作用 |
| --- | --- |
| 空格 | 播放 / 暂停 |
| ← / → | 上一事件 / 下一事件 |
| ↑ / ↓ | 跳到上一 / 下一章节书签 |
| + / - | 提高 / 降低倍速 |
| Home | 回到开头 |

连续拖动进度条时只呈现最后一次目标位置，过期定位不会覆盖新画面。

## 5. 章节书签

- 自动书签：切页、清空、PPT 翻页、点名、倒计时结束时自动生成；相距 2 秒内的相邻书签会合并。
- 手动书签：「在当前位置添加书签」；右键可重命名 / 删除；重命名后不再被自动规则覆盖。
- 书签提示显示「时间 · 第 N 页 · 摘要」。

## 6. 片段导出

1. 点击「导出视频（MP4）」。
2. 选择分辨率、倍速、「仅导出板书」、显示书写光标、显示章节信息。
3. 「片段（按章节）」下拉可直接选某章节：自动填入该章节开始时间，结束时间取下一章节或会话末尾，仍可手动微调。
4. 导出在后台进行，显示进度，可取消、可重试；导出期间可继续书写；成功或取消后清理半成品。
5. 有音频设备可勾选「同步录制讲解音频」；无设备时允许静默导出，并在结果中写明「已仅导出视频」。
6. 导出前会估算磁盘空间；不足时给出中文提示，不产生半成品。

## 7. 异常恢复

1. 应用被强制结束、休眠或断电后重新启动。
2. 若存在未完成会话，会话列表会出现带「（已恢复）」的条目，由最后一个快照 + 增量日志合并得到。
3. 恢复上限约为最后 2 秒；日志末尾截断的半行会被忽略，不会破坏整份日志。
4. 恢复出的会话可正常回放、导出；确认无误后可重命名，保留为正式记录。

## 8. 旧版会话迁移

1. 首次打开旧版会话时自动迁移：先把原文件复制为 `.bak`，再在内存中补齐书签与版本字段。
2. 迁移不写回原文件；下一次正常保存才写入新版格式。
3. 若迁移或校验失败：原文件保持不变，`.bak` 可用于手工回滚（改名回 `.json` 即可）。
4. 会话文件带 `.sha256` 校验；文件损坏时优先使用 `.bak`，没有备份则拒绝加载而不是把损坏内容当作正常会话。

## 9. AI 助教入口

- 浮条主栏与次级菜单均显示「AI」标记；右侧问号仍为「操作指南」，两者语义独立。
- 首次打开 AI 助教时会提示一次「框选内容后，可使用 AI 识别公式和图形。」，之后不再重复。
- 识别中 / 生成中 / 完成 / 出错通过按钮外的状态点、状态文字与进度环表达。

## 10. 本地处理与隐私

- 课堂记录、笔画数据、课件截图与讲解音频均保存在本机。
- 导出对话框会提示：姓名、头像与讲解音频仅本机处理，不会上传。
- 旧版迁移与完整性校验均在本地完成，不产生网络请求。
