# 选择、旋转与克隆

在桌面工具栏或白板底栏选择「选择」，从空白处按住拖动即可框选。选框与笔画相交即可选中，长直线不再因采样点稀疏而漏选。Ctrl 单击增选或取消对象，Ctrl / Shift 从空白处拖动可追加框选。

选框随对象旋转。顶部带圆形箭头的控制柄用于旋转，拖动时显示角度，Shift 按 15° 吸附。四角和四边控制柄用于缩放，Shift 拖动角点保持比例；细小对象会隐藏重叠的边中点控制柄。控制柄尺寸和顶部间距按界面 DIP 固定，不随画布缩放。

旋转交互参考 [Microsoft 的 PowerPoint 操作说明](https://support.microsoft.com/en-au/powerpoint/training/rotate-or-flip-an-object-in-powerpoint)。

桌面工具栏「克隆」会进入选择模式并切换克隆开关；白板选区面板提供「克隆模式」。开启后，按住选区主体向外拖动可生成副本，原对象保留且保持选中，可反复拖出多个副本。单击不生成副本，缩放或旋转控制柄仍修改选中对象。再次点击克隆开关或切换其他工具可结束克隆模式。

墨迹、形状、白板图片和视频可共同框选、移动、旋转和克隆。每次拖动或双指操作记录一个撤销单元；副本具有独立标识，复制图片/视频时共享只读文件字节，避免历史快照重复拷贝大文件。单对象旋转方向随 `.icink` 存档保留；旧存档仍可读取。

桌面工具栏和白板底栏新增「套索擦」。按住拖出任意形状的套索，抬手自动闭合，圈内或与边界相交的墨迹、形状、图片和视频会整项删除。过程中显示虚线轮廓与半透明区域；单击、直线滑动和未命中的圈选不生成擦除记录。切换工具、切换橡皮模式或取消输入会放弃本次套索；切换页面和进入鼠标模式也会取消。每次套索擦除对应一个撤销单元，恢复时保留对象身份和叠放顺序。
