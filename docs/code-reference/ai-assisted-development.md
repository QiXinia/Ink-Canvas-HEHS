# 鸿蒙交互实现代码参考

本文把交互反馈整理为可复用的需求提示和源码入口，供后续实现与代码审查使用。内容不包含会话原文、个人信息、机器路径、设备标识、账号配置或运行日志。提示描述目标行为，具体实现以当前源码和可复现验证为准。

## 工具栏布局与状态

提出工具栏或笔选项改动时，说明停靠位置、展开与折叠状态、可切换工具、滚动行为和最小触控尺寸。要求实现沿用已有状态，并说明窗口尺寸或屏幕变化时的布局策略。

可复用提示：

> 调整工具栏布局时，保留现有工具状态和触摸操作。明确展开、折叠、切换工具及内容滚动的行为，检查窄窗口和不同屏幕尺寸，并指出对应源码与验证方式。

源码入口包括 [BoardDock.ets](../../harmony/controls/src/main/ets/BoardDock.ets)、[PenPalette.ets](../../harmony/controls/src/main/ets/PenPalette.ets) 和 [页面入口](../../harmony/entry/src/main/ets/pages/Index.ets)。

## 触摸命中与墨迹输入

浮动工具、选择框和画布共享触摸区域时，分别说明命中目标、事件转交条件及拖动结束后的状态。验证工具控件可操作，画布输入不会被意外吞掉，手势不会同时触发两个目标。

可复用提示：

> 排查触摸或拖动问题时，先沿事件路径确认命中控件和坐标转换，再修正必要的命中区域或事件转交。分别验证工具操作、画布书写和拖动边界，不用延时或隐藏覆盖层掩盖问题。

源码入口包括 [页面输入与选择逻辑](../../harmony/entry/src/main/ets/pages/Index.ets)、[输入适配器](../../harmony/platform/src/main/ets/input/InputAdapter.ts) 和 [笔输入绑定](../../harmony/platform/src/main/ets/input/StylusBinding.ets)。

## 识别与异步结果反馈

异步识别或网络请求应区分成功、空结果、不可用和失败状态。空结果应明确告知用户，不生成未经识别的内容；取消或切换目标后，旧请求结果不能覆盖当前状态。

可复用提示：

> 为识别结果补齐成功、空结果、能力不可用、请求失败和取消状态。没有可靠结果时明确反馈原因，不推造识别内容。检查异步返回是否仍对应当前页面、选区和请求。

源码入口包括 [AI 助手逻辑](../../harmony/core/src/main/ets/ai/AiAssistant.ts) 和 [AI 捕获适配](../../harmony/platform/src/main/ets/assistant/AssistantCapture.ets)。

## 验证记录

提交实现时列出修改的源码、构建或测试命令，以及实际验证范围。设备操作只记录可重复观察到的结果，并区分代码检查、自动化测试和真机验证。不要在代码参考中保存个人工作目录、设备编号、密钥、连接配置或原始会话导出。
